# Sample k8sgpt Analysis Reports

This document contains example JSON reports generated by k8sgpt.

---

## Example 1: Healthy Cluster (No Issues)

### Command
```bash
make deploy-healthy
sleep 15
make analyze
```

### Output
```
No issues detected - cluster is healthy
```

### Report JSON (Empty Results)
```json
{
  "provider": "ollama",
  "errors": null,
  "status": "OK",
  "problems": 0,
  "results": []
}
```

## JSON Schema Reference

### Top-Level Structure
```json
{
  "provider": "string",        // LLM provider (ollama, openai, etc.)
  "errors": null | [],         // Analysis errors (null if none)
  "status": "string",          // OK | ProblemDetected
  "problems": number,          // Count of issues found
  "results": []                // Array of issue objects
}
```

### Result Object Structure
```json
{
  "kind": "string",            // Resource type (Pod, Deployment, etc.)
  "name": "string",            // Namespace/name
  "error": [                   // Array of error objects
    {
      "Text": "string",        // Error description
      "KubernetesDoc": "string", // Optional doc link
      "Sensitive": []          // Masked sensitive data
    }
  ],
  "details": "string",         // AI-generated explanation & fix
  "parentObject": "string"     // Parent resource (optional)
}
```

## Parsing Examples

### Extract Status
```bash
jq '.status' report.json
# Output: "ProblemDetected"
```

### Count Problems
```bash
jq '.problems' report.json
# Output: 2
```

### List All Error Messages
```bash
jq -r '.results[].error[].Text' report.json
# Output:
# Deployment has 0 available replicas
# manifest for nginx:invalid-tag not found
```

### Get Resource Names with Issues
```bash
jq -r '.results[] | "\(.kind): \(.name)"' report.json
# Output:
# Deployment: k8sgpt/broken-app
# Pod: k8sgpt/broken-app-xyz
```

### Extract AI Recommendations
```bash
jq -r '.results[].details' report.json | head -20
# Output: Step-by-step troubleshooting guide
```

### Filter by Kind
```bash
jq '.results[] | select(.kind == "Pod")' report.json
# Output: Only Pod issues
```

### Create Summary
```bash
jq '{
  total: .problems,
  status: .status,
  issues: [.results[] | {type: .kind, name: .name}]
}' report.json
```

Output:
```json
{
  "total": 2,
  "status": "ProblemDetected",
  "issues": [
    {
      "type": "Deployment",
      "name": "k8sgpt/broken-app"
    },
    {
      "type": "Pod",
      "name": "k8sgpt/broken-app-xyz"
    }
  ]
}
```

## Integration Examples

### Slack Notification
```bash
#!/bin/bash
OUTPUT=$(make analyze 2>&1)
if [ $? -eq 1 ]; then
  ISSUE_COUNT=$(jq '.problems' report.json)
  curl -X POST $SLACK_WEBHOOK \
    -H 'Content-Type: application/json' \
    -d "{\"text\":\"🚨 k8sgpt found $ISSUE_COUNT issues in cluster\"}"
fi
```

### Email Alert
```bash
#!/bin/bash
make analyze
if [ $? -eq 1 ]; then
  DETAILS=$(jq -r '.results[].error[].Text' report.json)
  echo "$DETAILS" | mail -s "k8sgpt Alert" team@example.com
fi
```

### GitHub Issue Creation
```bash
#!/bin/bash
make analyze
if [ $? -eq 1 ]; then
  ISSUES=$(jq -r '.results[] | "- \(.kind): \(.error[0].Text)"' report.json)
  gh issue create \
    --title "k8sgpt detected cluster issues" \
    --body "$ISSUES" \
    --label "k8s,incident"
fi
```
